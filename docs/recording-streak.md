# 連續記錄計算規則

- 一個使用者當地日曆日，只要至少有一筆已保存的餐點紀錄 **或** 一筆飲水紀錄，就算有記錄。AI 草稿不算，只有正式保存的資料列會納入。
- 日期由紀錄時間在使用者時區轉換而來；Web 使用 `afd_tz` cookie／個人檔案時區，Android 透過既有 `/api/me/timezone` 機制同步 IANA 時區，並以相同的時區解析器計算。
- 目前連續天數從今天開始計算；若今天尚未記錄，昨天的連續紀錄仍算目前連續天數。今天與昨天都沒有記錄時，目前連續天數為 0。最長連續天數保留所有已記錄日中最長的連續區間。
- 最近記錄日是截至使用者當地今天為止，最新的有記錄日期。尚無紀錄時回傳 `null`。
- 顯示文案保持中性：沒有紀錄時提供輕鬆開始的提示；連續紀錄中斷時保留最長紀錄並讓使用者自行決定何時繼續。

計算由 `src/lib/recording-streak.ts` 的純函式負責，不新增資料庫欄位或 migration。
