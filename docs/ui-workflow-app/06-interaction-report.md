# UI 交互体验分析报告

> 范围：仅针对 Flutter Android 手机原生体验；不设计 Web、平板或桌面，不修改代码。

## 一、交互设计哲学

- 每次操作都立即反馈；任何状态都说明「发生了什么、资料是否保留、下一步能做什么」。
- 动效温和、可信、克制。
- 输入、分析、储存、错误、恢复必须反馈；普通浏览不增加装饰动画。
- P0：`今日 → 记录方式 → 输入 → AI 分析 → AI 草稿审核 → 確認並儲存 → 餐點詳情`。
- 唯一正式边界：AI 分析完成不等于饮食记录已储存；只有用户完成 `確認並儲存` 后才进入正式餐点记录。
- 明确区分：本机保留、账号储存、已同步。
- 保存、上传、同步失败时保留原始相片、描述、手动内容、AI 草稿及用户修改。
- 不使用「吃得不好」「不及格」等非评判语言；营养颜色只表示分类。
- 使用 Material 3、NavigationBar、原生相机/相簿、Android Back 和系统 Insets；不将 Web 布局缩小到手机。

## 二、全局状态契约

| 状态 | UI 表现与台湾繁中案 | 用户可做什么 |
|---|---|---|
| `idle` | `記錄飲食` | 开始记录 |
| `input` | 输入页显示当前内容 | 继续、修改、清除、返回 |
| `captured` | `已收到內容`，显示相片/文字/手动摘要 | `開始分析`、返回修改 |
| `uploading` | `正在上傳…` | 取消、离开后恢复 |
| `analyzing` | `AI 正在分析這餐…` | 离开、查看状态中心 |
| `review` | `AI 估算・待確認`、`尚未儲存` | 编辑、删除、新增、确认 |
| `review-unsaved` | `你有尚未儲存的修改` | 继续编辑、保留、放弃 |
| `saving` | `正在儲存…` | 禁止重复提交 |
| `saved` | `已儲存` | 查看、编辑、删除 |
| `offline` | `目前離線`、最后同步时间 | 查看缓存、继续本机记录、重试 |
| `pending-sync` | `已保留在此裝置，待同步` | 查看、立即同步、稍后处理 |
| `error` | `處理未完成，內容已保留` | 重试、手动、稍后 |
| `permission-required` | 说明用途后请求权限 | 授权、稍后 |
| `permission-denied` | `目前無法使用…`、`前往設定` | 系统设置、相簿/手动替代 |
| `syncing` | `正在同步…`，显示范围和时间 | 查看、离开 |
| `sync-failed` | `同步未完成`，显示失败范围 | 重试、查看详情 |
| `empty` | 说明暂无资料 + 一个主 CTA | 创建、记录、授权、搜索 |
| `conflict` | 说明其他装置有更新 | 比较、保留本机、采用云端或合并 |

强制边界：AI 完成不等于储存；本机/账号/同步分开；保存失败保留全部；离线不伪装服务器成功；冲突不静默覆盖；Health Connect 拒绝不阻塞饮食；关键错误不只 SnackBar。

## 三、组件微交互

### 通用状态

Android 无 Web hover，不依赖悬停。`pressed` 使用 Material overlay 80–120ms；`focused` 使用 2dp 边框与约 3dp focus halo；`selected` 同时用文字、图标、边框和 indicator；所有主要目标至少 48×48dp。

### 按钮

- 默认：主按钮高 52dp，暖琥珀实心；次要使用 Outlined/Text Button。
- 按下：短暂加深，80–120ms，不改变布局。
- 聚焦：可见焦点环，TalkBack 读名称和状态。
- 选中：用于切换/筛选，显示 `已選取` 或图标。
- 禁用：降低对比度，保留原因，不能只靠灰色。
- 加载：保留语义，如 `正在儲存…`，可附小 spinner。
- 成功：短暂 `已儲存`/勾选，但页面保留正式状态。
- 错误：恢复为 `重試儲存`/`重試`，并显示持久说明。

### 输入框

- 56dp 高，始终有 label；单位用辅助文字。
- 聚焦后自动滚动到可见区域，不自动清空。
- 数值字段支持全选；禁用字段显示原因。
- 错误使用边框、字段下方具体说明和错误摘要；聚焦第一个错误字段；不强烈抖动。
- 数值范围在离开字段时校验，避免输入过程中打断。

### NavigationBar/AppBar

- 根导航固定 `飲食 / 健康 / 設定`；选中使用 Material indicator + 标签 + 图标，不用营养色。
- 子页隐藏 NavigationBar，使用 AppBar 返回。
- 切换 Tab 不阻塞其他 Tab；页面内部显示骨架/错误。

### 列表/卡片

- 不透明 Material surface、1dp 边框/分隔线，行至少 64dp。
- pressed overlay 不跳动；焦点可见，TalkBack 读对象、日期、状态和动作。
- 选择模式使用 Checkbox/顶部工具栏；加载使用固定高度骨架；错误行内提供重试。
- 删除可使用按钮/更多菜单；左滑只能快捷方式，不能是唯一入口。

### AI 草稿项目

- 默认 `AI 估算・待確認`、名称、份量、热量。
- 用户修改显示 `已由你修改`，不再表现为纯 AI 结果。
- 项目级失败不删除其它可用项目。
- 重新估算必须明确触发，不能静默覆盖手动修改。

### 固定 CTA

- 表面背景 + 1dp 顶部分隔线 + 52dp 按钮；避让键盘、手势、导航。
- 默认 `確認並儲存`；加载 `正在儲存…`；成功 `已儲存`；错误 `重試儲存` + `餐點尚未儲存，內容已保留`。

### Bottom Sheet / Dialog / Banner

- Sheet：220–320ms，28dp 顶部圆角，32×4dp 把手；只承载来源、短筛选、短确认、简单编辑；支持 Back、关闭、遮罩、下拖、安全区。
- Dialog：只删除、放弃、冲突或不可逆确认；焦点限制在 Dialog 内，关闭后回到触发按钮；不承载 AI 审核、长表单和同步日志。
- 关键状态使用持久 Banner/状态中心入口；SnackBar 仅补充低风险提示。
- Banner 必须包含对象、状态、资料是否保留和下一步 CTA。

## 四、页面状态与转场

### 今日

空：`今天還沒有飲食紀錄` + `記錄第一餐`；加载优先显示缓存，无缓存显示骨架；错误说明 `已保留目前可用的內容` + `重試`；离线显示 `目前離線` 与最后同步。点击 `記錄飲食` → 来源 Sheet；待处理 → 状态中心；餐点 → 详情；日期 → 日期选择/历史。

### 来源 Sheet

四个等权选项：`拍照記錄`、`從相簿選取`、`文字描述`、`手動記錄`。相机/相簿不可用时保留手动。关闭方式为 Back、关闭、遮罩、下拖；选择后先关闭再进入全屏/系统页。

### 相机/相簿

最多 5 张，显示数量和逐张移除。相机取消不建空任务。权限拒绝显示用途与 `前往設定`，并提供相簿、描述、手动替代。读取错误保留其它输入并可重选。

### 描述/手动

必要字段优先，营养渐进展开；字段错误贴近字段并聚焦第一个错误。键盘时 CTA 可见；Back 有未保存提示。空白描述：`請先描述你吃了什麼。`；网络错误：`描述已保留；目前無法開始 AI 分析。`

### AI 分析

上传和分析分开：`正在上傳…` → `AI 正在分析這餐…`。允许离开，状态中心可恢复；完成显示 `AI 已完成初步估算，尚未儲存。` + `查看草稿`；失败显示 `分析未完成，原始內容已保留` + `重新分析`/`改用手動記錄`/`稍後處理`。

### AI 审核

全屏单栏；`AI 估算・待確認`、可编辑项目、固定 `確認並儲存`。无修改直接 saving；有修改标记 `review-unsaved`。Back 显示保留/放弃/继续 Dialog。保存成功 → 详情；失败 → `儲存未完成，草稿仍保留` + 重试。

### 餐点详情/编辑/删除

详情展示时间、相片、食物、营养、来源、储存/同步状态。编辑全屏，底部 `儲存變更`；保存失败不覆盖原记录。删除 Dialog：`刪除這筆餐點？`，成功回原列表，失败保留详情。

### 健康授权/同步

健康页先显示连接状态，未授权不显示为错误。说明页解释数据类别和用途，再进入系统权限。允许/部分允许/拒绝/无数据分开表达；拒绝不阻塞饮食。同步可离开；结果显示范围、时间、成功/失败批次和重试。

### 状态中心

分 `待處理 / 進行中 / 稍後重試 / 已完成`；每项有查看/重试/返回来源/完成时间。状态中心失败也要页面内重试；通知关闭后仍能由今日、状态中心和冷启动恢复任务。

### 我的食物

选取模式和管理模式分开；管理页搜索、最近/常用、筛选、排序和可见 `選取`/Checkbox。长按可快捷进入但不是唯一方式；封存不影响历史。无结果提供 `清除搜尋`、`新增食物`、手动替代。

### 历史/回馈

日期选择、前后日期和回今天按钮；回馈生成失败不阻塞餐点查看；自动昨日 Dialog 改为今日页内可召回卡片。

## 五、手势与键盘

- 系统 Back：子页返回；Sheet 关闭；输入页第一次收键盘，第二次返回；未保存触发 Dialog。
- 边缘返回与 AppBar 返回一致；关键手势都有按钮替代。
- 下拉刷新提供 `重新整理` 按钮；日期左右滑提供前一天/后一天/日期选择；相片横滑提供缩图和上一张/下一张；双指缩放提供放大/缩小/重设；长按批量提供 `選取`/Checkbox；左滑操作提供更多菜单。
- 焦点顺序：返回 → 标题 → 餐别 → 描述/食物 → 份量 → 单位 → 增加项目 → 营养 → 来源 → CTA。
- AI 审核：状态 → 相片/描述 → 名称 → 份量 → 热量 → 营养 → 新增/删除 → `確認並儲存`。
- 字段获得焦点后自动滚到键盘上方；固定 CTA 移到 IME 上方；数值用数字键盘；多行描述 Enter 换行、完成只收键盘；中文组合输入不能误触提交。
- 处理状态栏、刘海、导航栏、手势区和键盘 Insets；窄屏单栏，短屏折叠说明，横向仍手机单栏。

## 六、可访问性

- 所有控件可聚焦，顺序符合视觉和任务。
- TalkBack 示例：`午餐，今天 12:30，已儲存，450 大卡，雙擊查看詳情`；`AI 估算・待確認，尚未儲存`；`已由你修改`；`已保留在此裝置，待同步`。
- 动态上传/分析/储存/同步/错误用可读的 live 状态；错误摘要先读再聚焦字段。
- Sheet/ Dialog 焦点进入并返回触发元素；删除和危险动作有文字名称。
- 正文对比度至少 4.5:1，大字 3:1；状态不只靠颜色；目标 48dp，主 CTA 52dp，列表 64dp。
- 字体 1.3–1.5 倍不截断；允许卡片变高；相片替代描述不把 AI 不确定结果写成事实。
- Reduced Motion 关闭位移、缩放、抖动、循环动画，保留文字状态和静态进度。
- 深色使用不透明表面；通知默认不显示完整餐点、热量、健康细节。

## 七、关键流程交互细节

### P0 新增餐点并储存

`記錄飲食` → 来源 Sheet → 原生相机/输入 → `開始分析` → 上传/分析 → `查看草稿` → 编辑 → `確認並儲存` → 详情。保存中禁重复；失败保留相片、描述、草稿和修改；快速入口不能跳过审核。

### 离线、失败与恢复

离线显示 `目前離線` 和最后同步；输入可本机保留；上传任务转 `待同步`；网络恢复后 WorkManager 继续；失败提供重试、手动、稍后。放弃必须明确删除本机草稿。

### 冲突

显示本机与云端版本时间、修改字段和来源；只有产品确认支持时提供合并；不提供无法可靠执行的动作；任何选择都要二次确认并保留未采用版本（若产品规则允许）。

### 健康授权

健康概览 → 说明 → 系统授权 → 返回重读状态；部分授权列出缺失类型；拒绝返回健康页并继续饮食；同步显示范围、结果、失败与日志。

### WorkManager、通知与冷启动

后台任务与状态中心同步；通知只展示不敏感的任务状态；通知权限拒绝后任务不丢；冷启动先会话恢复，再消费 `taskId/objectId/date/intendedAction`，任务存在进入对象页，已完成进入详情，失效进入状态中心。

## 八、动效与性能

- 按下 80–120ms；聚焦 100–160ms；状态 160–200ms；Dialog 180–220ms；Sheet 220–320ms；图表 240–400ms。
- 进入淡入 + 4–8dp 位移；退出淡出/短位移；Tab 轻淡入；不弹跳、不无限 Spinner。
- 目标 60fps（约 16.7ms/帧）；同时动画区域不超过两个；相片缩图约 512px；低端设备回退静态 surface、静态进度和系统转场。

## 十、交互冲突与待确认

- 离线是否允许正式确认与储存，草稿保存多久。
- 本机、账号、同步的正式定义。
- 冲突策略：选择、合并或副本。
- AI 信心度与营养编辑规则；手动是否可跳过 AI。
- Health Connect 读写范围、回填、频率。
- 通知默认策略、隐私遮罩、失败提醒频率。
- 相片保存、第三方发送、删除/导出。
- 最低 Android 版本、设备范围、横向支持。

## 十一、下游约束

- **Content**：统一 `餐點`、`飲食紀錄`、`AI 估算・待確認`、`確認並儲存`、`待同步`、`我的食物`；错误先说资料是否保留；健康用中性、行动导向语气。
- **Visual**：暖琥珀只用于行动/选中/确认；AI 草稿用 brand.soft；营养色只分类；错误、离线、同步、冲突同时用文字和图标；不使用玻璃/3D/粒子/持续视差。
- **Form**：首屏少字段，渐进营养编辑；单位、范围、错误、IME 和 CTA 必须明确。
